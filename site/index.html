Nested clips on three Androids

Each view runs a line-by-line port of that Android version's drawing code on Skia, here in your browser. Shapes, clips and gradients match the devices we test on. Edge smoothing comes from today's Skia, so an edge can differ by a pixel. Hover a render to compare the same pixels across all three.
