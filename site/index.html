vdt

Turns SVGs into Android VectorDrawables. Drop one in to see the XML it writes and how Android draws that XML, from API 21 to today.

On Android

Each view is drawn by a line-by-line port of that version's drawing code from the Android Open Source Project, running on Skia in your browser. Shapes, clips, and gradients match the devices we test against; edge smoothing can differ by a pixel.
